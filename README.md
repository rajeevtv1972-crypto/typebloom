# TypeBloom

A friendly browser typing practice tool.

## Page flow

- `main.html` is the landing page shown first.
- Clicking **Let's begin** / **Begin your journey** opens `index.html`.
- `index.html` contains the typing practice app.
- `_redirects` sends the Cloudflare Pages root `/` to `main.html`.
- `about.html`, `contact.html`, and `privacy-policy.html` provide the site information and legal pages.
